# 우테코 8기 프리코스 1주차 과제: 계산기

## 구현 기능 목록

실행 로직 순으로 작성되었습니다.

### 1. MESSAGES

- 애플리케이션 실행, 결과 안내, 에러 발생 시 출력할 메시지를 상수로 지정한다.

### 2. inputParser / ParserTest

- 사용자의 입력을 숫자 배열로 파싱하는 컴포넌트.
- 기본 구분자와 파싱할 전체 문자열을 초깃값으로 설정하고, 입력이 공백일 경우 빈 배열을 반환한다.
- match 메서드를 사용하여 사용자가 커스텀 구분자를 지정했는지 패턴을 대조한다.
- 커스텀 구분자가 숫자이거나 공백일 경우 에러를 발생시키고, 유효할 경우엔 구분자 목록에 추가한 뒤 파싱할 문자열을 업데이트한다.
- 마지막으로, 확정된 구분자들을 기준으로 문자열을 분리하여 순수한 숫자 배열을 반환한다.
- inputParser는 계산이나 앱의 흐름에 영향을 주지 않는 순수한 파서 컴포넌트로 구현한다.

### 3. calculator / CalculatorTest

- 숫자 배열을 reduce를 이용해 합산하는 계산기 컴포넌트.
- 입력된 배열이 비어있거나 존재하지 않을 시 0을 반환한다.
- 배열에 음수가 포함되어 있을 시 에러를 발생시킨다.
- 유효한 배열일 경우, reduce를 통해 모든 숫자를 합산한 결과를 반환한다.
- 파서와 마찬가지로 순수하게 계산만 담당하는 컴포넌트로 구현한다.

### 4. App

- readLineAsync를 통해 사용자 입력을 받고, MESSAGES 상수를 사용하여 안내 문구를 출력한다.
- 사용자 입력을 inputParser와 calculator를 통해 처리한다.
- try...catch 구문을 통해 예외가 발생할 경우를 대비한다.
