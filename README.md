# 우테코 8기 프리코스 1주차 과제: 문자열 계산기

## ✨ **기능 목록**


### **📥 입력 기능**

- **계산할 문자열**
    - 쉼표(`,`) 또는 콜론(`:`)을 구분자로 가지는 문자열을 입력받는다.
    - `//`와 `\n` 사이의 문자를 커스텀 구분자로 지정할 수 있다.
    - **예외 처리:** 아래의 경우 에러를 발생시킨다.
        - 입력된 숫자 배열에 음수가 포함된 경우
        - 커스텀 구분자가 숫자인 경우
        - 커스텀 구분자가 공백인 경우

### **📤 출력 기능**

- **계산 결과**
    - `결과 : 10`
    - 입력된 문자열의 모든 숫자를 합산한 결과를 출력한다.
    - 입력값이 공백이거나 null일 경우 0을 출력한다.

## 🛠️ **컴포넌트별 역할**

https://github.com/junhocode/javascript-calculator-8/blob/junhocode-refactor/README.md
- **View (InputView / OutputView)**
    - 콘솔 입출력을 전담하는 컴포넌트.
    - 사용자에게 안내 메시지를 출력하고, 계산할 문자열을 입력받는다.
    - 최종 계산 결과나 에러 메시지를 출력하는 역할을 수행한다.
- **constants / messages**
    - 애플리케이션 전반에서 사용되는 상수와 메시지를 관리한다.
    - 애플리케이션 실행 안내 문구, 결과 메시지, 에러 메시지 등을 포함한다.
- **InputParser**
    - 사용자로부터 입력받은 문자열을 숫자 배열로 파싱하는 역할을 책임진다.
    - 기본 구분자(`,`, `:`)와 커스텀 구분자를 처리한다.
    - 순수하게 문자열을 파싱하는 역할만 담당하며, 계산이나 유효성 검증은 책임지지 않는다.
- **Calculator**
    - 숫자 배열의 합산을 책임지는 계산기 컴포넌트.
    - `reduce`를 이용하여 배열의 모든 요소를 더한 값을 반환한다.
    - 순수하게 계산만 담당하는 컴포넌트로 구현한다.
- **Validator**
    - 입력값에 대한 모든 유효성 검증을 책임지는 컴포넌트.
    - 음수 포함 여부, 커스텀 구분자의 유효성 등 비즈니스 로직상의 모든 예외 조건을 검사한다.
    - `Parser`와 `Calculator`로부터 검증 로직을 분리하여 각 컴포넌트가 단일 책임 원칙을 지키도록 돕는다.
- **AppController**
    - 사용자 입력부터 최종 결과 출력까지, 전체 애플리케이션의 흐름을 제어하는 지휘자 역할.
    - 각 컴포넌트(Model, View, Parser, Validator)에 필요한 작업을 요청하고 데이터를 전달한다.

## 🚗 **실행 플로우**


1. **프로그램 시작**
    - `AppController`의 `run` 메서드가 호출되며 전체 프로세스가 시작된다.
2. **문자열 입력**
    - **Controller → View:** `InputView.getExpression()`을 호출해 사용자 입력을 요청한다.
    - **사용자 입력 예시:** `"//;\n1;2;3"`
3. **문자열 파싱**
    - **Controller → Parser:** 입력받은 문자열을 `InputParser.parse()`에 전달한다.
    - **파싱 결과:** `['1', '2', '3']`과 같은 숫자 문자열 배열
4. **입력값 검증**
    - **Controller → Validator:** 파싱된 배열을 `Validator`에 전달하여 음수 포함 여부 등을 검증한다.
    - 예외 상황 발생 시, Controller가 에러를 잡아 View를 통해 메시지를 출력하고 프로세스를 종료한다.
5. **결과 계산**
    - **Controller → Model:** 유효성 검증을 통과한 숫자 배열을 `Calculator.sum()`에 전달한다.
    - **계산 결과:** `6`
6. **최종 결과 출력**
    - **Controller → View:** 최종 계산된 합계를 `OutputView.printResult()`에 전달해 콘솔에 출력한다.
